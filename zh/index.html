打印用外壳

打印外壳：螺钉柱、止口与凹槽、卡扣

Boss 在草图的每个点上生成螺钉柱或热熔螺母柱：尺寸合适的嵌件孔、根部圆角，筋可以旋转，也可以逐根去掉。Lip / Groove 沿抽壳盒体的边缘做出凸缘，并在盖子上做出与之配合的凹槽——圆角处也可以——使两半对齐并严密合拢。Snap Fit 在壁上长出带卡钩的弹性条，卡钩伸出边缘之上：它在边缘以下很深处与壁相连并带倒角，因此牢固，打印无需支撑。Hole ▸ Insert 可在任意位置生成热熔螺母孔，M2 至 M5。

真正的螺纹

真正的螺纹，可直接 3D 打印，只需几次点击

可以直接打印的真实螺旋螺纹，而不是贴图——在已有的孔中或轴上：选择圆柱面和规格，或让 Auto 按孔自动匹配。ISO 公制、UNC / UNF、G、梯形、平顶的 Print-friendly，或 Custom——自定螺距、牙型角和深度，适用于瓶罐、盖子以及各种非标准螺纹。可设置任意打印间隙（默认 0.2 毫米），让打印件能够拧合。这里的每一种螺纹都是为 3D 打印设计的。在表面上生长出的凸起圆螺纹特别适合自制盖子、油桶和罐子的瓶口等：就像注塑件一样，螺纹从表面无中生有地升起，又回到表面中。

AI × 3D 打印

用 AI 为 3D 打印优化——尽量减少支撑

让你的 AI 为打印准备零件：它可以把悬垂改为 45° 倒角，给零件一个平整的底面，并拆分无法一次打印的部分。每处修改都是历史中的普通特征——可以检查、编辑或撤销。

3D 草图

3D 草图中的 3D 线——沿虚拟立方体绘制

在空间中绘图非常方便：原点周围有一个虚拟点阵立方体，大小和间距由你决定。线可以沿三个方向延伸：在任意层——XY、XZ、YZ——或整个立方体（Cube）中选点；Tab / Shift+Tab 切换层，点可以用鼠标拖动。Lines、Spline 或 Through points——画好的线可直接作为 Sweep 和 Loft 的路径。

照片 → 真实尺寸

一张照片加一次测量——得到真实尺寸

插入照片，点击两点并输入一个真实长度：整张图片随之缩放，你就能在上面按真实毫米进行设计。照片拍歪了？Horizontal 或 Vertical 会把它旋转到这条线变平直。

Emboss · Engrave

文字和任意草图——在任意面上凸起或雕刻

Emboss 把文字或任意闭合草图——字母、标志、星形——凸起，Engrave 则把它刻进去：可在平面上，可包裹在圆柱和圆锥上，也可投影到球面上。超出某个面的字母会延续到与之平滑相接的面上，混合曲面同样可用。任意已安装字体、多行、西里尔字母、沿曲线排布文字；Evenly round 可让文字均匀绕满一圈。

齿轮 · 蜗杆

齿轮和蜗杆传动——一个对话框搞定

Spur Gears 无需草图即可直接生成啮合的一对齿轮：渐开线齿形，直齿或斜齿（5–45°），可按齿数、传动比或中心距确定尺寸，并带轴孔。Worm Gear 生成蜗杆和蜗轮，1–6 头。第三个齿轮可与已有齿轮啮合；Make Assembly 把每个齿轮放进各自的零件中。

阵列

阵列：在两个面之间均匀分布，去掉不需要的副本

Equal spacing 把副本均匀分布在两个边界之间——两个面、两条边或两个点——无需自己计算间距。Excluded：直接在模型上点击不需要的副本即可去掉；✕ 可恢复任意一个。特征可用矩形、圆形阵列和 Mirror（镜像）；草图中还有 Along Path——沿任意曲线（直线、圆弧、样条）排列副本。

拆分打印

零件比打印机还大？拆开——用燕尾榫

在草图中画出切割线——直线、圆弧或燕尾形——Split ▸ Keep all 会沿着它切开零件，每一块都成为独立的实体。间隙可任意设置：用 Offset 按间隙大小再画一条线——两线之间的窄条也会成为实体；删除它，间隙就有了。然后 Make Assembly 直接把这些块变成装配体，每块都是可直接打印的零件；燕尾榫把打印好的各块连在一起。

AI · MCP

连接你的 AI——逐步说明

ProstoCAD 内置 MCP 服务器（AI Link）：无需为它下载任何东西。任何支持 MCP 的 AI 程序都能在你的 ProstoCAD 窗口中工作——查看零件、测量 STL、构建可编辑的特征。

A快捷方式：Connect AI

  1. 在 ProstoCAD 中打开零件或导入 STL。
  2. Tools ▸ AI ▸ Connect AI——或点它的箭头，选择 Claude Code、Codex 或 Gemini CLI。已安装：立即在零件所在文件夹启动，并已连接 ProstoCAD。尚未安装：终端（Windows 上为命令提示符）会自动安装它——缺少 Node.js 时也一并安装——然后连接并启动。在那里用你自己的账号登录一次即可。
  3. 用你自己的话告诉 AI 你想要什么：
    “在 ProstoCAD 中把这个 STL 重建为零件，先做锐边。” “把这个零件优化为适合 3D 打印，尽量减少支撑。” “在顶面的孔里做 M6 螺纹。”

Gemini CLI 已不再支持个人 Google 账号登录：请选择 Use Gemini API Key，粘贴在 aistudio.google.com/apikey 免费创建的密钥（Create API key）。ProstoCAD 会替你保存：How to Connect ▸ Gemini API key ▸ Save key。

常见问题

常见问题的简短解答。

ProstoCAD 免费吗？

是的。下载和使用都免费。

需要安装 FreeCAD 吗？

不需要。ProstoCAD 内置 FreeCAD 1.1.3 内核。它有自己的设置，不会改动已安装的 FreeCAD。

macOS 提示无法验证此应用

测试版未经过 Apple 公证。点按完成（不要点“移到废纸篓”），打开系统设置 ▸ 隐私与安全性，滚动到“已阻止使用 InnCadPlus…”，点按仍要打开，然后输入密码确认。只需操作一次。

在 macOS 13 和 14 上，也可以右键点按应用 ▸ 打开。或者在终端中运行： xattr -dr com.apple.quarantine /Applications/ProstoCAD.app

能在 Intel Mac 或 Linux 上运行吗？

Linux：版本即将推出。Intel Mac：此版本不支持。目前 ProstoCAD 可在 Apple 芯片的 Mac（M1 或更新，macOS 13 或更高版本）和 Windows 10 / 11 x64 上运行。

支持读写哪些文件格式？

打开 FreeCAD 文件（.FCStd）、STEP 和 STL；导入 IGES、OBJ 以及作为描图底图的 JPG / PNG / BMP 图片；导出 STEP（精确实体）和 STL（带精度滑块，供切片软件使用）。

FreeCAD 能打开我的文件吗？

能。零件是 FreeCAD 的 PartDesign 实体，草图是 Sketcher 草图，装配体使用 FreeCAD 自己的关节：都是普通的 .FCStd 文件。ProstoCAD 也能打开在 FreeCAD 中创建的文件。

使用 AI 需要什么？

一个用你自己的账号登录的 AI 命令行工具：Claude Code、Codex 或 Gemini CLI（Codex 和 Gemini CLI 需要 Node.js）。Connect AI 会告诉你去哪里获取。AI Link 只在你的电脑上监听，并且只接受持有 ProstoCAD 密钥的程序；关闭它，任何 AI 都无法访问 ProstoCAD。

出了问题，怎么报告？

手册第 11 章说明了日志的位置以及需要发送的内容；然后给我们写信——见联系。
